## 3. Overall Project Requirements

## Technology Stack

- Frontend: HTML, CSS, JavaScript (Bootstrap or Material UI may be used)

- Backend: PHP (Mandatory)

- Database: MySQL (Mandatory)

## Functional Requirements

Each project should include:

- Separate Admin and Student/User interfaces

- Secure login functionality

- Complete CRUD (Create, Read, Update, Delete) operations

- Responsive and user-friendly interface

- Database integration using PHP and MySQL

- Proper form validation

- Navigation menus and consistent page layouts

- Search and filtering functionality where applicable

Students are encouraged to include additional innovative features beyond the minimum requirements.

## 6. Important Guidelines

- Each group must select only ONE project topic from the five provided.

- All applications must include a properly designed database.

- CRUD operations should be implemented throughout the system where appropriate.

- The user interface should be professional, responsive, and easy to use.

- Students are encouraged to add creative and innovative features to enhance their project.

- The project should demonstrate teamwork, coding best practices, and proper documentation.
