## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Mockup HTML | The user opens a static file or a dev-server-served file; the file ships with the design tokens, the theme script, and the FOUC guard. No network request other than the CDN Bootstrap JS/CSS and the Inter font. |
| localStorage -> Theme controller | The theme controller writes `tickettrade.tickettrade.theme` to localStorage. The value is one of `light`/`dark`/`system`; any other value is treated as missing per the priority-order algorithm. The controller does not write any other localStorage key in this plan. |
| CSS bundle -> Page first paint | The FOUC-guard inline script runs synchronously before the CSS link; it sets `<html data-theme="...">` from localStorage + system preference. A malicious or misconfigured script that sets `data-theme` to an invalid value would not break the layout (the variable falls back to light or dark defaults at the cascade level) but would visually shift the page. |
