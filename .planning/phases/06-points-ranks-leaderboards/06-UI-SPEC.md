# Phase 6 — UI Design Contract

> Visual and interaction contract for **Points, Ranks & Leaderboards**. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Source of truth:** `06-CONTEXT.md` D-01..D-08 (LOCKED) + `config/ranks.php` (6-tier table, LOCKED) + `public/assets/css/tickettrade.tokens.css` (design tokens, LOCKED from Phase 1) + `public/assets/css/tickettrade.components.css` (existing component CSS, Phase 1 + 5). ## Spacing Scale

Declared values (multiples of 4, mapped to existing `tickettrade.tokens.css` `--space-*` tokens):

| Token | Value | Token | Usage |
|-------|-------|-------|-------|
| xs | 4px | `--space-1` | Icon gaps, tier-progress bar height, inline padding |
| sm | 8px | `--space-2` | Compact element spacing, leaderboard row vertical padding, toast gap |
| md | 16px | `--space-4` | Default element spacing, leaderboard card padding, profile section padding |
| lg | 24px | `--space-5` | Section padding, leaderboard card gap, tier-progress label-to-bar gap |
| xl | 32px | `--space-6` | Layout gaps between leaderboard cards on desktop |
| 2xl | 48px | `--space-8` | Major section breaks (profile header → gamification sections) |
| 3xl | 64px | `--space-10` | Page-level spacing (not new in Phase 6) |

**Phase 6 exceptions:**
- **Tier progress bar height = 8px** (lockstep with `.session-progress__bar` from Phase 4; uses `--space-2` indirectly)
- **Rank badge (md) = 28px tall** (matches `--font-size-headline-md` so the badge label sits on a 1.4× line-height)
- **Rank badge (sm) = 20px tall** (inline with body text on leaderboard rows)
- **On-Break pill = 20px tall** (inline with sm badge)
- **Velocity flag pill = 24px tall** (slightly larger to signal state; 12px font-size for readability)

**Rationale:** all values map to existing tokens; no new spacing tokens. Phase 6 does not introduce any new exception beyond the 5 listed component sizes (which reuse the 8/20/24/28 values already established by `.session-progress`, `.bottom-nav__item`, `.analytics-card`, and `.toast`).

## Typography

Mapped to existing `tickettrade.tokens.css` font tokens. **No new sizes in Phase 6** — the 4 sizes below are the locked set per Phase 1 D-25.

| Role | Size | Weight | Line Height | Token |
|------|------|--------|-------------|-------|
| Body (default) | 14px | 400 (regular) | 1.5 | `--font-size-body-md` / `--font-weight-regular` |
| Label (small) | 12px | 500 (medium) | 1.4 | `--font-size-body-sm` / `--font-weight-medium` |
| Heading (section) | 20px | 600 (semibold) | 1.3 | `--font-size-headline-md` / `--font-weight-semibold` |
| Display (hero / KPI) | 28px | 700 (bold) | 1.2 | `--font-size-display-md` / `--font-weight-bold` |

**Phase 6 weight policy (locked):** exactly 2 weights are introduced in Phase 6 component CSS:
- `var(--font-weight-medium)` (500) for the sm rank badge label, on-break pill, velocity flag pill, leaderboard rank number
- `var(--font-weight-semibold)` (600) for the leaderboard nickname and the tier-progress "X of Y" label

All other weights (400, 700) are inherited from the existing token system.

**Font family:**
- Display (`--font-family-display`): Inter → system-ui fallback — used for the leaderboard section titles ("Campus Legends Wall", "Weekly Risers", "Category Leaders", "Streak Kings")
- Body (`--font-family-body`): system-ui — used for leaderboard rows, profile sections, tier progress labels
- Mono-code (`--font-family-mono-code`): ui-monospace — NOT used by Phase 6 visual surfaces (no ticket codes or UUIDs in the leaderboard or tier progress UI)
