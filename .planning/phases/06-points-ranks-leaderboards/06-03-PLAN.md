<objective>
Ship the four leaderboards (Campus Legends Wall, Weekly Risers, Category Leaders, Streak Kings) backed by summary tables refreshed by an idempotent daily cron, plus the JSON cache that the public `/leaderboards` page reads. Wire the daily cron as `POST /admin/cron/daily` extending `Admin\Action\CronAction` per AD-11. Mount the rank badge, tier progress, on-break pill, velocity flag pill, and recent activity sections on the owner Profile page.

Purpose: PTS-09 requires four privacy-preserving leaderboards; PTS-08 requires the On-Break + velocity signals visible to the owner; PER-05 requires the summary tables. The JSON cache is the cold-load optimization that keeps the public page a file read.

Output: migrations 020 + 021, a new `Leaderboard` bounded context (Service + Model + Action + View + partial), extended Profile view (owner) + new public_profile sections for the gamification pills, daily cron dispatch, and the unit + integration tests covering the new endpoints + the leaderboard query correctness.
</objective>
